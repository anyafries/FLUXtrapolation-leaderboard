FLUXtrapolation leaderboard

This leaderboard tracks machine-learning model performance on the FLUXtrapolation benchmark for extrapolating ecosystem fluxes. Each model is scored on prediction error of three fluxes (ET, GPP, NEE) in three extrapolation scenarios (temporal, spatial, temperature) for six timescales.

Skill score

The skill score compares a model's error with the linear-regression baseline lr. For every cell in the table it is 1 − RMSE(model) / RMSE(lr), and the score shown is the average of these over all timescales and all extrapolation scenarios currently selected. 0 means the model does as well as lr, 1 would mean zero error, and a negative score means the model is worse than lr. Higher is better.
